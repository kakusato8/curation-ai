## 個人情報配信BEアプリ 仕様書

### 1. はじめに

本仕様書は、Gemini APIを利用し、ユーザーが設定した情報を定期的にメールで配信するバックエンドアプリケーション（以下、本アプリ）の開発に関する詳細を記述します。

### 2. アプリケーション概要

本アプリは、ユーザーがウェブ画面から設定した情報カテゴリに基づき、Gemini APIを介して情報を収集し、指定された頻度（毎日、毎週、毎月）でユーザーにメール配信します。また、手動での即時配信機能も提供します。

### 3. 技術スタック

* **言語:** TypeScript
* **フレームワーク:** NestJS
* **データベース:** Firebase Firestore
* **ホスティング:** Firebase Hosting / Cloud Functions for Firebase
* **API:** Google Gemini API
* **メール送信:** Firebase Extensions (例: "Trigger Email"など、または別途SMTPサービス)

### 4. 機能要件

#### 4.1. ユーザー管理

* **ユーザー登録・認証:** Firebase Authenticationを利用してユーザーの登録、ログイン、ログアウト機能を提供します。
* **プロフィール管理:** ユーザーは自身のメールアドレスなどを管理できます。

#### 4.2. 情報設定機能

* **情報カテゴリ設定:**
    * ユーザーは、配信を希望する情報カテゴリを複数選択・設定できます。
    * 情報カテゴリは、具体例として「流行っている漫画の情報」「流行っているアニメの情報」「ポケモンカードの流行レシピ」「音楽ライブ情報」「お笑いライブ情報」「その他イベント情報」「新しいAIモデル」などが挙げられますが、これらは柔軟に追加・編集可能な構造とします。
    * 各情報カテゴリに対し、詳細なクエリ（例: 漫画のジャンル、ライブの地域など）を設定できるようにします。
* **配信頻度設定:** 各情報カテゴリに対し、以下のいずれかの配信頻度を設定できます。
    * 毎日 (1日に1回)
    * 毎週 (1週間に1回、曜日指定可能)
    * 毎月 (1か月に1回、日付指定可能)
* **即時配信ボタン:** 各情報カテゴリ、または全情報カテゴリに対して、ユーザーが任意のタイミングで情報を即時メール配信できる機能を提供します。

#### 4.3. 情報収集・生成機能

* **Gemini API連携:**
    * 設定された情報カテゴリとクエリに基づき、Gemini APIを呼び出して関連情報を収集・生成します。
    * Geminiへのプロンプトは、効果的な情報収集のために調整可能とします。
    * 収集した情報は、メール配信に適した形式（要約、リスト形式など）に整形します。
* **エラーハンドリング:** Gemini APIからの応答エラーや情報取得失敗時の処理を定義します。

#### 4.4. メール配信機能

* **メール生成:** 収集・整形された情報を基に、パーソナライズされたメールコンテンツを生成します。
* **メール送信:** 設定された配信頻度に基づき、ユーザーの登録メールアドレスへ自動的にメールを送信します。
* **即時メール送信:** ユーザーが手動で即時配信を要求した場合、即座にメールを送信します。
* **配信ログ:** 配信履歴（日時、内容、ステータス）を記録します。

### 5. データベース設計 (Firebase Firestore)

#### 5.1. `users` コレクション

| フィールド名    | 型     | 説明                          |
| :-------------- | :----- | :---------------------------- |
| `uid`           | string | Firebase Authentication UID   |
| `email`         | string | ユーザーのメールアドレス      |
| `createdAt`     | Timestamp | ユーザー作成日時              |
| `updatedAt`     | Timestamp | 最終更新日時                  |

#### 5.2. `user_settings` コレクション

| フィールド名       | 型       | 説明                                   |
| :----------------- | :------- | :------------------------------------- |
| `userId`           | string   | `users` コレクションの `uid` を参照   |
| `settings`         | array    | ユーザーが設定した情報カテゴリの配列   |
| `settings[].id`    | string   | 設定ID (UUIDなど)                      |
| `settings[].categoryName` | string   | 情報カテゴリの表示名 (例: "流行漫画") |
| `settings[].geminiQuery` | string   | Gemini APIへのプロンプト文字列       |
| `settings[].frequency` | enum     | 配信頻度 (daily, weekly, monthly)      |
| `settings[].weeklyDay` | number?  | `frequency`が`weekly`の場合の曜日 (0:日曜, 1:月曜...) |
| `settings[].monthlyDay` | number?  | `frequency`が`monthly`の場合の日付 (1-31) |
| `createdAt`        | Timestamp | 設定作成日時                           |
| `updatedAt`        | Timestamp | 最終更新日時                           |

#### 5.3. `delivery_logs` コレクション

| フィールド名    | 型        | 説明                                   |
| :-------------- | :-------- | :------------------------------------- |
| `userId`        | string    | `users` コレクションの `uid` を参照   |
| `settingId`     | string    | `user_settings` 内の設定IDを指す (オプション) |
| `deliveryType`  | enum      | 配信タイプ (scheduled, instant)        |
| `status`        | enum      | 配信ステータス (success, failed)       |
| `errorMessage`  | string?   | 配信失敗時のエラーメッセージ           |
| `deliveredAt`   | Timestamp | 配信日時                               |
| `contentSummary`| string?   | 配信内容の簡単な要約 (デバッグ用)      |

### 6. APIエンドポイント (NestJS)

#### 6.1. 認証関連

* `POST /auth/register`: ユーザー登録
* `POST /auth/login`: ユーザーログイン
* `POST /auth/logout`: ユーザーログアウト

#### 6.2. 情報設定関連

* `GET /settings`: ユーザーの全設定を取得
* `POST /settings`: 新しい情報カテゴリ設定を追加
* `PUT /settings/:id`: 特定の情報カテゴリ設定を更新
* `DELETE /settings/:id`: 特定の情報カテゴリ設定を削除
* `POST /settings/instant-delivery/:id`: 特定の情報カテゴリを即時配信
* `POST /settings/instant-delivery/all`: 全情報カテゴリを即時配信

### 7. スケジュール機能

* **Firebase Cloud Functions (Cron Jobs):**
    * 毎日実行されるCloud Function: 全ユーザーの`user_settings`を巡回し、`frequency`が`daily`の設定、またはその日に該当する`weekly`、`monthly`の設定を持つユーザーに対して情報収集・メール配信トリガーを発火させます。
    * 即時配信リクエストは、HTTPトリガーのCloud Functionで処理します。

### 8. セキュリティ

* **認証・認可:** Firebase AuthenticationとNestJSのGuard/Interceptorを用いて、各APIエンドポイントへのアクセスを制限します。
* **環境変数:** Gemini APIキーなどの機密情報は、Firebase Functionsの環境変数として安全に管理します。
* **データ保護:** Firestoreのセキュリティルールを設定し、不正なデータアクセスを防ぎます。
* **レートリミット:** 必要に応じて、Gemini APIへのリクエストにレートリミットを設定し、API利用規約に準拠します。

### 9. エラーハンドリングとロギング

* **NestJSの例外フィルター:** エラー発生時に適切なHTTPレスポンスを返します。
* **Firebase Cloud Logging:** Cloud Functionsの実行ログやアプリケーションのカスタムログを記録し、デバッグや監視に利用します。

### 10. 開発環境・デプロイ

* **開発環境:** 各開発者のローカル環境でNestJSアプリケーションを実行できるように設定します。
* **デプロイ:** Firebase CLIを使用して、Firebase Cloud FunctionsおよびFirestoreにデプロイします。
